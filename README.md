# stone zhang

个人博客，基于 [AstroPaper](https://github.com/satnaing/astro-paper) 主题。

站点：https://zhang-stone.github.io

## 本地开发

需要 Node.js >= 22.12.0。

```bash
pnpm install
pnpm dev
```

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `pnpm dev` | 启动开发服务器 |
| `pnpm build` | 类型检查、构建，并生成 Pagefind 索引 |
| `pnpm preview` | 预览构建结果 |

站点配置在 `astro-paper.config.ts`，文章在 `src/content/posts/`。
